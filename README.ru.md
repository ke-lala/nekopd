# Neko-i2pd для Android

[简体中文](README.md) · [English](README.en.md) · [Русский](README.ru.md)

Неофициальная ветка Android на основе [PurpleI2P/i2pd-android](https://github.com/PurpleI2P/i2pd-android) 3.0.0. Версия приложения — **3.0.1**. Ветка `android-vpn-webapps` добавляет поиск и импорт адресной книги, встроенный браузер I2P и маршрутизацию VPN по приложениям, сохраняя существующие консоль и туннели i2pd. Это не официальный выпуск PurpleI2P.

## Возможности

- **Адресная книга:** содержит снимок из 71 записи `hosts.txt` релизной версии Java I2P ([источник](https://github.com/i2p/i2p.i2p/blob/b21f0c5ee22edc4fb7fa0bc4bd8cca255e629ec0/installer/resources/hosts.txt)). Можно искать домены, просматривать и копировать их b32-адреса, а также импортировать стандартный `hosts.txt` и CSV вида `hostname,b32`. Встроенный список статический и автоматически не обновляется. Импорт добавляет записи; при конфликте сохраняется уже имеющаяся. Чтобы разрешать вновь импортированные домены, перезапустите работающий маршрутизатор.
- **Встроенный браузер I2P:** использует локальный HTTP-прокси i2pd `127.0.0.1:4444` и разрешает только страницы `.i2p` и ресурсы этих сайтов. Если системный WebView не поддерживает `PROXY_OVERRIDE`, браузер покажет ошибку и не переключится на прямое соединение с публичным Интернетом.
- **VPN-маршрутизация по приложениям:** выберите приложения в настройках VPN. Hev Socks5 Tunnel 2.19.3 (нативная сборка для API 23) направляет их трафик к локальному SOCKS5-прокси i2pd `127.0.0.1:4447`. Обычно Android разрешает только один активный VPN. Без рабочего I2P outproxy обычные соединения с публичным Интернетом могут блокироваться; при сбое VPN незаметного перехода на прямое соединение нет.
- **Портал WebApps:** I2P Mail (`mail.i2p`) и Web IRC (`webirc.coldhell.i2p`) открываются во встроенном браузере. Это ссылки на сервисы сети I2P, а не почтовый или IRC-сервер внутри APK.
- **Фон консоли:** можно выбрать или удалить изображение фона из фотографий телефона.
- **Функции i2pd:** исходные консоль и туннели сохранены. В этой ветке не добавлен отдельный WebApp для загрузки и раздачи BitTorrent.

## Совместимость с Android

Цель — распространённые конфигурации телефонов и эмуляторов: **Android 6.0/API 23 или новее**, ABI `arm64-v8a`, `armeabi-v7a`, `x86` и `x86_64`. Это не гарантирует совместимость со всеми прошивками производителей и устройствами. Встроенный браузер также зависит от поддержки `PROXY_OVERRIDE` установленным WebView. Проверены сборка APK и модульные тесты; это не означает полноценного тестирования на всех физических устройствах.

## Загрузка

APK доступен на странице [GitHub Releases](https://github.com/ke-lala/nekopd/releases). Версия 3.0.1 — **тестовая сборка с debug-подписью** для ручной установки. Она не подписана для распространения через Google Play и не должна рассматриваться как полностью проверенный стабильный выпуск.

## Сборка из исходного кода

Требуются JDK 17 или новее, Android SDK (API 37), NDK `29.0.14206865`, `make`, `cmake`, `perl`, `curl` и `zip`. Клонируйте репозиторий вместе с подмодулем i2pd:

```bash
git clone --recurse-submodules --branch android-vpn-webapps \
  https://github.com/ke-lala/nekopd.git
cd nekopd
export ANDROID_HOME="$HOME/Android/Sdk"
export ANDROID_SDK_ROOT="$ANDROID_HOME"
export ANDROID_NDK_HOME="$ANDROID_HOME/ndk/29.0.14206865"
binary/jni/build.sh
./gradlew :app:assembleDebug
```

Универсальный debug APK создаётся в `app/build/outputs/apk/debug/`. Для производственного выпуска используйте собственный ключ подписи; не добавляйте ключи, пароли или `keystore.properties` в репозиторий.
